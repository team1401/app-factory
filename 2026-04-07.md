# 2026-04-07 — Overnight App Factory (T1)

## Brainstorm (problem-first)
1) **Allergen Matrix (Shelf Label Tool)** — *Pain:* maintaining a staff-facing allergen chart is a constant spreadsheet nightmare and drifts out of sync with recipes. *Who:* school nutrition directors, cafeteria managers, catering leads, small restaurants with inspections/allergen-disclosure requirements.
2) **FieldClaim Photo Packager** — *Pain:* insurance adjusters need consistent photo sets + naming + claim notes; folders get messy and rework happens. *Who:* independent property adjusters.
3) **Specimen Chain-of-Custody Log (lite)** — *Pain:* small clinics mishandle sample handoffs/labels in ad‑hoc notes. *Who:* urgent care ops managers.
4) **Studio Patch Recall** — *Pain:* live sound engineers forget console patching + phantom power state between gigs; mistakes are expensive. *Who:* FOH/monitor engineers.
5) **Clinic Room Turnover Timer** — *Pain:* tracking room clean/ready status across multiple rooms without buying enterprise software. *Who:* small dental / PT / outpatient clinics.
6) **Warehouse Slotting QuickSheet** — *Pain:* ad-hoc “where does this SKU live?” decisions cause pick errors. *Who:* small warehouse supervisors.

## Picked
**Allergen Matrix (Shelf Label Tool)**

### Why this one won
- **High-frequency pain** (weekly/daily): menus, substitutions, supplier changes.
- **Underserved by existing tools** in the small/medium space: most options are either spreadsheets or part of expensive enterprise suites.
- **Clear “compliance pressure”** = willingness to pay.
- Can be valuable **offline** on a shared kitchen computer.

## Design Direction (summary)
- Style: **“Retail Shelf Label System”** (barcode bands, price-tag metaphors, bright paper)
- Signature: barcode header strip + price-tag empty state + allergen dot headers

## Architecture Sketch
- Data model: `Ingredient[]` (with allergen flags) + `Dish[]` (ingredient ids + optional may-contain flags)
- Storage: localStorage (offline-first), export/import JSON
- Components: Matrix table, Dish editor, Ingredient editor, Print view

## Implementation Notes
- Validation: name length checks; safe JSON import normalization
- States: empty (price-tag), loading not needed (all local), error toasts for import failures
- Accessibility: semantic table for matrix, aria labels for marks, keyboard-friendly buttons
