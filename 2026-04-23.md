# App Factory — Daily Brainstorm
**Date:** 2026-04-23
**Status:** Complete

## Brainstormed Concepts (7)

### 1. ShiftPulse
- **Pain:** Shift workers need to know *exactly* what time they're working on any given day across rotating schedules
- **User:** Healthcare shift workers (RNs, CNAs), ER techs, police on 3x12/4x12/24/48 rotations
- **Frequency:** Daily — they check every morning to know when to wake up
- **Current solutions:** When I Work, WhenToWork, PDF schedules — require manual setup, don't auto-calculate future times
- **Visual style:** Hospital Wall Bulletin — clinical beige, blue header bar, color-coded shift blocks (day=amber, evening=indigo, night=deep purple), analog clock countdown

### 2. CNAFile
- **Pain:** Construction estimators waste hours manually calculating material takeoffs from PDF blueprints
- **User:** Small GC estimators, independent subs (electrical, plumbing, framing), architectural assistants
- **Frequency:** Weekly or per project — every time they bid
- **Current solutions:** PlanSwift, Bluebeam ($1000+), manual Excel — overkill for small subs, require training
- **Visual style:** Blueprint Overlay — navy background, cyan accents, semi-transparent grid, monospace labels, architectural dimensions

### 3. MenuPrism
- **Pain:** Restaurant owners need to calculate actual food cost accounting for shrinkage, waste, portion variance, supplier fluctuations
- **User:** Restaurant owners, executive chefs, F&B directors at independent restaurants
- **Frequency:** Monthly when suppliers change prices, weekly when creating new items
- **Current solutions:** Excel templates, ChefTec ($200/mo overkill), static apps — no recipe scaling, waste tracking
- **Visual style:** Kitchen Order Ticket — thermal paper background, monospace numbers, red cost alerts, receipt footer with margin %

### 4. RackMap Pro
- **Pain:** Sysadmins lose track of what's in each server rack — rack position, U location, device, IP, service
- **User:** Sysadmins at SMEs (50-500 servers), colo managers, IT support with multiple racks
- **Frequency:** Constant — daily tickets, weekly maintenance, monthly audits
- **Current solutions:** Spreadsheets, whiteboards, nothing — manual lookup wastes precious minutes
- **Visual style:** Rack Elevator — gunmetal background, color-coded 1RU/2RU/4RU blades, U-position labels, device icons by type, live search highlight

### 5. FormSprint
- **Pain:** Small businesses waste hours typing client data from paper forms into digital systems
- **User:** Independent contractors (HVAC, plumbing, electricians), cleaners, consultants, insurance adjusters
- **Frequency:** Daily — every client interaction generates paper forms
- **Current solutions:** Scannable apps, generic OCR, manual re-entry — no field mapping, no export to common formats
- **Visual style:** Scan Tray Dashboard — office beige, scanner bed metaphor, highlighted detected fields, green success checkmark, paper form cards

### 6. CallSheet
- **Pain:** Event photographers need to create/share call sheets with timeline, shot list, contacts, logistics — static Canva templates don't auto-update
- **User:** Wedding photographers, event photographers, photojournalists, video production assistants
- **Frequency:** Per event — weekly or biweekly for active pros
- **Current solutions:** Canva templates, Google Docs — static, no real-time updates, no vendor sharing
- **Visual style:** Film Production Call Sheet — cream paper, typewriter font, black header bars, color-coded timeline blocks, emergency contact box

### 7. PalletCalc
- **Pain:** Warehouse managers waste time manually calculating box-to-pallet packing — maximizing space while respecting weight/stacking constraints
- **User:** Small e-commerce warehouse operators, shipping coordinators, fulfillment center managers
- **Frequency:** Daily — every shipping cycle
- **Current solutions:** Manual calculation, expensive WMS, spreadsheets — no optimization algorithms
- **Visual style:** Warehouse Forklift Display — yellow/black hazard stripes, dashboard aesthetic, 3D pallet visualization, amber LED numbers, barcode scanner simulation

## Selected Concept: ShiftPulse

**Rationale:**
- **Daily recurring pain** — shift workers check schedule EVERY SINGLE MORNING
- **Universal audience** — nurses, factory workers, police, firefighters, retail managers all on rotating shifts
- **Zero good mobile experience** — everyone checks on phone, but schedules are PDFs/spreadsheets
- **Clear freemium path:** Free for 1 schedule, $3/mo unlimited, $5/mo team sharing
- **Viral potential** — shift workers share schedules with colleagues, post on nursing subreddits
- **Underserved niche** — every hospital has different schedule format; no one-size-fits-all solution
- **Differentiated visual identity** — "Hospital Wall Bulletin" is unique and useful (clinical clarity, not pretty)

**Visual Style: Hospital Wall Bulletin Board**
- **Palette:**
  - Clinical beige (#F4F2EA) background
  - Institutional blue (#2A5C8A) header
  - Shift amber (#F5C842) day shift
  - Shift indigo (#4A6FA5) evening shift
  - Shift purple (#5B4D63) night shift
  - Alert red (#D02020) critical
  - Status green (#2E7D52) active
- **Signature Elements:**
  - Analog clock face countdown timer ("Time until next shift") in real-time
  - Color-coded shift blocks with bold sans-serif times
  - Weekly grid view with current day highlighted
  - Shift pattern preview showing "Mon/Wed/Fri 7A-7P" text
  - Clean institutional grid with blue separator lines
  - Bold headers, minimal decoration, maximum clarity

**Tech Stack:** React + TypeScript + Vite, served via nginx in Docker
