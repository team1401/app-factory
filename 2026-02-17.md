## Why I Built It

The trending concept for February 2026 is **"vibe coding"** — coined by Andrej Karpathy, it describes the mode where developers describe what they want in plain language and AI builds it. It's exploded into mainstream developer culture and there's massive demand for tools that bridge the gap between the casual description and the formal spec that AI tools actually need.

The existing tools either go too deep (full project management) or too shallow (just a chat box). VibeSpec hits the sweet spot: takes your casual vibe, extracts intent, and outputs something structured and actionable.

---

## What It Does

- **Feature detection engine**: 20+ keyword rules detect features (auth, real-time, payments, maps, gamification, etc.) from casual language
- **Requirements generator**: Produces MUST / SHOULD / NICE-TO-HAVE requirements based on detected features
- **Tech stack mapper**: Recommends the right libraries and infrastructure per detected features (e.g., mentions "offline" → recommends Service Worker / IndexedDB)
- **User story writer**: Generates 5 user stories in standard format
- **Risk flagging**: Calls out common pitfalls (timezone edge cases in streaks, API rate limits, mobile drag-and-drop complexity)
- **Complexity score**: 1–10 score with estimated build time (weekend project → multi-month MVP)
- **AI build prompt**: A copy-paste-ready prompt for Cursor, Claude, or Copilot
- **Save specs**: localStorage-based save system for up to 10 specs
- **Download as .md**: Exports full spec as a markdown file

All 100% frontend — no backend, no API keys, no database. Pure browser.

## Visual Style Direction

**Style Name:** Neo-Swiss Brutalism

**Concept:** The discipline and grid-obsession of Swiss International Typographic Style (think Helvetica, the Basel School, Müller-Brockmann's grid systems) meets brutalist web design's refusal to soften anything. White as religion. Black as law. One accent color — acid green — that punches you in the face.

**Palette:**
- Background: `#FFFFFF` (pure white — non-negotiable)
- Surface: `#F4F4F0` (warm off-white for cards)
- Primary: `#000000` (black — borders, text, buttons)
- Accent: `#00CC44` (acid green — the only color)
- Danger: `#FF2200` / Warning: `#FF9900`

**Typography:**
- Headings: Space Grotesk 700 (tight letter-spacing, uppercase)
- Body/UI: Space Grotesk 400-600
- Code/Labels/Monospace: JetBrains Mono

**Signature Elements:**
1. Giant outlined "BUILD SPEC" hero title (transparent fill, 3px -webkit-text-stroke black)
2. Swiss grid pattern baked into the body background (1px grid lines at 40px intervals)
3. Step-by-step animated processing bar in acid green (like a Swiss railway departures board)
4. Black CTA buttons with 4px offset drop shadow on hover (brutal push effect)
5. Acid green stripe on the left edge of every tech stack item
6. Output header block rendered entirely in acid green background with black type

**Anti-sameness check:** Zero glassmorphism. Zero gradient. Zero dark background. No rounded corners anywhere. Maximum contrast, maximum Swiss grid discipline.
