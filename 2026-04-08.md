# App Factory — 2026-04-08

## Brainstorm (problem-first)

1) **ConservaForm — museum condition reports**
- Pain point: Condition reports for loans/moves are still Word/PDF template hell; inconsistent “where is the damage?” notes; hard to print cleanly.
- Who has it: museum registrars, art conservators, gallery operations teams.
- Frequency: every incoming/outgoing loan, internal move, acquisition (often multiple times/week).

2) **ShiftCue — live stagehand run-of-show + headset call log**
- Pain point: calling cues + noting issues during live shows is chaotic; paper cue sheets don’t capture timestamps and repeat problems.
- Who has it: theater stage managers, live event crews.
- Frequency: every show + rehearsal.

3) **TrailBench — field test log for trail running shoe reviewers**
- Pain point: reviewers forget mileage-by-surface, conditions, and failure notes across multiple shoes.
- Who has it: gear reviewers, run coaches, high-volume runners.
- Frequency: weekly.

4) **TattooAftercare Desk — standardized aftercare plan builder (non-medical) + client checklist**
- Pain point: inconsistent aftercare instructions lead to angry clients and rework; artists repeat themselves constantly.
- Who has it: tattoo shops.
- Frequency: multiple times/day.

5) **LabLabel Guard — tube/plate label sanity checker + print layout preview**
- Pain point: labs mis-label samples and the “label format” lives in tribal knowledge; mistakes are expensive.
- Who has it: wet labs, research assistants.
- Frequency: daily.

6) **PropertyWalk Punchlist — offline walkthrough punchlist that prints like a formal handover doc**
- Pain point: property managers do walk-through notes in random apps then struggle to produce a clean handover list.
- Who has it: property managers, facilities ops.
- Frequency: weekly/monthly.

## Pick: ConservaForm (why)
- Strongest problem/solution fit with clear users and recurring workflow.
- “Print-to-PDF condition report” is a real deliverable people must produce; the app directly replaces annoying template work.
- Can be **local-first** (privacy-friendly) and still be immediately useful.
- Clear freemium path: multi-report library, photo attachments, shared links, team templates, e-sign, audit trail.

## Design direction (unique)
- **Style genre:** *Manila Folder Registrar Packet*
- **Layout:** single printable “report sheet” with two-column working area
- **Typography:** system sans for readability + monospace chips/IDs for registrar vibe
- **Palette:** Manila (#F3EAD4), Report Paper (#FFFDF6), Ink (#1B1916), Registrar Red (#B12A1C), Archive Teal (#1F5D73), Catalog Yellow (#F0C330)
- **Signature element:** angled red CONDITION REPORT stamp + 3×3 Object Map grid with live finding counts per zone

## Architecture sketch
- **State:** one `ObjectRecord` stored in `localStorage` (local-first)
- **Data model:** Object details + `entries[]` findings (zone, category, severity, summary, details)
- **Export/Import:** JSON download/upload
- **PDF output:** browser print with print CSS
- **No backend in v1** (privacy + speed)
