# KeyChart — Chord Chart Transposer

Paste any chord chart, select a target key via the Circle of Fifths compass rose, and get the chart back fully transposed in seconds.

## Features
- Auto-detects source key from chart content
- Interactive Circle of Fifths compass rose for target key selection
- Capo suggestions for guitarists
- Handles complex chords: maj7, m7b5, dim7, sus4, add9, slash chords
- Sharp/flat preference toggle (auto-set per key)
- Copy to clipboard

## Running
docker compose up -d

## Env vars
None required.
