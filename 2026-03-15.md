## Why IncidentCanvas Won

- **Strongest pain/frequency match**: Every company with a production system has incidents. Engineers hit this problem repeatedly — not once per year.
- **Clear deliverable**: "Generate post-mortem in one click" is the kind of value proposition that gets upvoted on Product Hunt because it replaces 3 hours of work.
- **Underserved niche**: PagerDuty and OpsGenie are alerting tools, not timeline builders. Notion/Confluence are post-mortem templates. Nothing sits in the gap of "real-time event logging during the incident itself."
- **Product Hunt test**: "Oh yeah, I've spent hours doing Slack archaeology after an incident" — everyone in DevOps/SRE says this.
- **Style opportunity**: "Teletype Wire Room" — hadn't been done. Rich teletype paper + dark sidebar + wire service dispatch aesthetic. Completely distinctive.

## Design Direction

**Style:** "Teletype Wire Room" — Mid-century AP/UPI wire service newsroom. Warm teletype paper background with horizontal ruled lines, dark wire machine housing sidebar, Courier Prime monospace for all timeline events (mimicking wire dispatches). Events are logged as wire dispatches with priority flags.

**Palette:**
- Background: #F4F0E6 (warm teletype paper)
- Paper: #FDFBF5 (white page)
- Sidebar: #252018 (dark wire machine housing)
- Primary: #C4430A (urgent red)
- Amber: #CC8800 (bulletin)
- Green: #3A7A52 (resolution)
- Blue: #2A5C8A (investigation)
- Purple: #6A3A8A (comms)

**Typography:** Courier Prime (all timeline events — typewriter feel) + IBM Plex Sans (UI chrome) + IBM Plex Mono (metadata, stats, badges)

**Signature Element:** Wire service priority flags: **FLASH ★** (P1) / **URGENT** (P2) / **BULLETIN** (P3) / **ADVISORY** (P4) — color-coded, displayed on every event card exactly like AP/UPI wire service dispatch headers. Timeline background uses repeating horizontal ruled lines mimicking teletype paper.

**Layout:** Three-panel: dark sidebar (incident list), main feed (wire-service timeline), right meta panel (stats, affected systems, contributing factors, export).

## Features Shipped

- Incident lifecycle management: Active → Mitigated → Resolved, with REOPEN
- Live UTC elapsed timer (red when active, gray when resolved)
- Wire service header per incident (service ID, incident number, start time)
- Event types: Detection / Investigation / Mitigation / Comms / Resolution / Escalation / Learning / Note
- FLASH ★ / URGENT / BULLETIN / ADVISORY dispatch flags based on severity
- Timestamp + UTC offset from incident start for every event
- Author attribution per event
- Custom timestamp override support
- Live incident metadata: affected systems, user impact, commander, severity selector
- Contributing factors tag toggles: Infrastructure, Code Defect, Config Change, Human Error, Dependency, Capacity, Security, Process Gap
- Incident stats: event count, time-to-detect (TTD), time-to-resolution (TTR), comms count
- Event type breakdown visualization
- One-click post-mortem generator (full structured markdown-style output)
- Copy timeline as plain text
- Seed data: realistic P1 checkout incident with 10 events
- localStorage persistence
- Keyboard shortcuts: E (log event), N (new incident), Escape (close modal)
