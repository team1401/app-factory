# App Factory — 2026-02-27

## Brainstorm

1. **Mile Marker** — Personal campsite logbook for full-time nomads. Log stays, rate sites, track states visited and average cost. Export to CSV/JSON. Personally useful to Brian daily; sellable to RV/Airstream community.
2. **RateForge** — IT consulting rate calculator. Enter desired income, overhead, vacation days → get justified hourly rate + project rates. Helps Brian's Nutanix consulting; broad SaaS appeal.
3. **Hookup Scout** — Crowdsourced cell signal + utility ratings at specific campgrounds. Big nomad pain point, but needs a user base to be useful.
4. **Pack Manifest** — Gear/cargo inventory manager for RV/van dwellers. Track what's stowed where, weight, checklists.
5. **Nomad Lease Tracker** — Track campsite reservations, membership expiry (Thousand Trails, KOA), blackout dates.

## Winner: Mile Marker

**Why:** The most immediately useful to Brian's daily life AND has genuine money-making potential. Every Airstream owner, full-timer, and RV nomad needs a personal campsite log — where they stayed, what it cost, how quiet it was, what the cell signal was like, whether pets were allowed. No existing tool has a beautiful, opinionated UX for this. Could be monetized at $5/month with sync + sharing features (v2), pitched to Airstream Club International where Brian is already Indie Streamers president.

RateForge was tempting but more niche (IT consultants only). Mile Marker has a market of 11+ million RV households in the USA.

## Build Details

- **Port:** 3134 (airstream)
- **Stack:** Pure HTML/CSS/JS, localStorage, nginx:alpine
- **Visual Style:** WPA Federal Art Project — flat bold colors, no gradients, silhouetted landscape art as card headers, Art Deco Oswald typography
- **Signature Element:** Six landscape card types (mountains, forest, desert, plains, coast, canyon) each rendered as a layered clip-path silhouette in WPA poster style
- **Features shipped:**
  - Log campsites with name, location, dates, cost, hookup type, landscape type
  - Rate overall, quietness, scenery (star ratings)
  - Cell signal bars (1–5)
  - Pet-friendly flag
  - Free-text notes
  - States visited tracker (all 50 shown, visited highlighted)
  - Search + filter by hookup + sort by date/rating/cost
  - Export CSV + JSON
  - Seed data preloaded (3 real Brian-relevant campsites: Padre Island, Big Bend, Flagstaff dispersed)
  - Delete confirmation modal
  - Toast notifications
  - Responsive mobile layout
