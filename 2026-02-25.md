## Winner: Drift

**Why this one:** Brian drives across the country in an Airstream and stays at dozens of locations per year — boondocking spots, campgrounds, overnight Walmart stops, scenic pull-outs. There's no good tool to log all of these, rate them, and see them on a map. Every nomad faces this problem. Google Maps "saved places" is too generic. Campendium covers campgrounds but not personal ratings for boondock spots. Drift fills a real gap.

**SaaS potential:** Start as a personal log → add user accounts → build a community map of crowd-sourced ratings → monetize via $5-8/month subscription or RV club accounts. The data network effect is real.

## Build

- **App:** Drift — Nomad Location Log
- **Port:** 3132 (airstream)
- **URL:** http://100.97.65.28:3132
- **Tech:** Node.js + Express + better-sqlite3 + Leaflet.js + Vanilla JS
- **Visual Style:** "Risograph Zine" — two-color riso print aesthetic
- **Build time:** ~2 hours
- **Notable issues:** 
  - Forgot to add `<link rel="stylesheet" href="style.css">` in HTML (caught in QA)
  - Helmet's `upgrade-insecure-requests` CSP directive blocked local file loads on HTTP (fixed by setting it to null)

## Visual Identity

- **Style:** Risograph Zine — inspired by lo-fi indie print / riso press aesthetic
- **Palette:** Newsprint cream (#F2EDD0), deep teal (#1A4D5C), coral red (#F04A1E), riso yellow (#FFDC00)
- **Signature element:** Riso misregistration effect — the "DRIFT" logo has a coral-colored ghost offset by 2px x/y behind the main teal text, mimicking actual riso print color misregistration. Halftone dot pattern overlay on sidebar. IBM Plex Mono + Bebas Neue + Barlow Condensed type trio.
- **Palette completely distinct from all prior builds**

## Features Shipped

- Interactive Leaflet map (OpenStreetMap, click to add locations)
- 6 location types: boondock, campground, RV park, city, overnight stop, other
- 3-dimension ratings: cell signal, scenery, access ease (1-5 dots)
- Date tracking with automatic nights calculation
- Cost per night tracking + hookup type
- Full-text notes field
- Stats dashboard: total spots, total nights, total spend, avg/night
- List view with filter by type + sort by date/rating/cost/name + search
- Detail panel shows on marker/list click
- SQLite persistence (data survives restarts)
- Health check endpoint
- Edit and delete existing spots
- Responsive layout (mobile + desktop)
