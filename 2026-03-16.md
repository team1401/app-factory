# App Factory Build — 2026-03-16

## Brainstorm: 7 Problem-First Ideas

1. **Meal Timing Coordinator**
   - Pain: Cooking a multi-dish meal and having everything ready simultaneously is genuinely hard. You need to backward-schedule from a serve time. Nobody does this on paper; people wing it and things come out cold.
   - Who: Anyone cooking a dinner party, holiday meal, or any meal with 3+ components
   - Frequency: Every dinner party, holiday, Sunday roast — weekly for hosts
   - Existing solutions: None good. Recipe sites give cook times in isolation, not coordinated.
   - **SELECTED — strongest problem/solution fit, universally relatable, zero good existing tools**

2. **Workshop Facilitator Timer**
   - Pain: Corporate trainers running 6-hour sessions with multiple segments need to track transitions
   - Who: Instructional designers, trainers
   - Frequency: Weekly
   - Problem: Somewhat solved by generic timer apps. Less differentiated.

3. **Contractor Permit Deadline Tracker**
   - Pain: Building permits expire if inspection milestones are missed; DIYers pay re-permit fees
   - Who: DIY homeowners doing renovations
   - Frequency: Only during an active project — occasional user problem

4. **Wholesale Product Sheet Generator**
   - Pain: Etsy/craft sellers pitching boutiques spend 2+ hours in Canva making spec sheets
   - Who: Small-batch handmade sellers
   - Frequency: Every new product line — potentially strong, but one-shot usage pattern

5. **Sobriety Milestone Tracker**
   - Pain: Private, non-clinical milestone tracking for people in recovery
   - Who: People tracking sober time
   - Passed on: Requires sensitive UX work; needs ongoing input to be meaningful

6. **Shift Handoff Brief Generator**
   - Pain: Nurses/supervisors doing shift handoffs miss critical items in verbal handoffs
   - Who: Healthcare, hospitality, manufacturing shift workers
   - Strong problem — but writing a structured handoff doc is somewhat covered by existing tools

7. **Retake Tracker for Photographers**
   - Pain: Event photographers miss planned shots because they don't track what they've captured vs. shot list
   - Who: Wedding/event photographers
   - Niche — strong problem but small audience

---

## Winner: mise — Meal Timing Coordinator

**Why this one:**
- The pain is universal and immediately relatable ("yeah I always screw up timing")
- Zero existing tools solve it cleanly — you'd have to build a spreadsheet
- Recurring weekly use case for anyone who cooks for guests
- Natural freemium path: free = manual entry; paid = recipe import, sync, saved templates
- GateMate test passes easily: "I want all my food done at the same time" → "oh yes that problem is real"

## Design: Nordic Tasting Menu

- **Style:** Nordic Tasting Menu — inspired by Noma/Fäviken-era Scandinavian fine dining design
- **Palette:** Off-white #F8F5EF bg · White #FFFFFF surfaces · Forest green #2C5F3E accent · Terracotta #9E4A2A warnings · Warm sand #C4A882 borders · Near-black #1A1714 text
- **Typography:** Work Sans (humanist sans) + IBM Plex Mono for all timers/times
- **Signature:** Gantt chart timeline ribbon — each dish is a horizontal bar split into prep (diagonal hatch), cook (solid forest green), and rest (dotted) zones. In Service Mode, a live playhead advances through the timeline like a music player scrubber.
- **Layout:** Single-scroll setup view → full-screen Service Mode with live action queue

---

## What Was Built

- **Backward scheduling engine:** All dishes calculated from a target serve time (totalMin = prep + cook + rest; startMin = serveTime - totalMin)
- **Visual Gantt timeline** with per-phase color coding
- **Oven conflict detection:** Flags when two dishes with oven categories (protein/starch/bread/dessert) have overlapping cook phases
- **18 quick-add presets:** Roast chicken, prime rib, salmon, mashed potatoes, gravy, rolls, etc.
- **Service Mode:** Full-screen with live clock, countdown, per-dish status badges (Pending → Prepping → Cooking → Resting → Ready), live playhead, action queue with 5-item window, auto-completed action log
- **localStorage persistence:** All dishes and serve time survive page refresh
- **Responsive:** Works on mobile (375px) and desktop
