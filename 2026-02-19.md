# App Factory Build — February 19, 2026

## What Was Built

**CinePrompt — AI Video Prompt Builder**

A cinematic prompt engineering studio for AI video generators: Seedance 2.0, Sora, RunwayML, and Pika. Users compose a shot step-by-step (shot type → camera movement → lighting → mood → color grade → target generator), get a live-updating optimized prompt with a typewriter animation, then copy it directly into their chosen generator.

## Why

ByteDance's **Seedance 2.0** exploded onto the internet this week — going massively viral after an X user posted a clip of Tom Cruise and Brad Pitt fighting on a rooftop, generated from "a 2 line prompt." The Motion Picture Association condemned it, Disney threatened legal action, and Elon Musk reacted. AI video generation crossed a threshold into mainstream cultural conversation.

The problem: everyone wants to use these tools, but most prompts are bad. CinePrompt solves that — a structured, jargon-free interface that guides users through cinematic thinking: shot composition, camera movement, lighting, tone, and color grade. Each generator gets an optimized prompt format (Seedance gets prose, Runway gets keywords with flags, Pika gets concise punchy copy).

Immediately useful, completely self-contained, zero backend.

## Visual Style Direction

**"Golden Age Cinema" — Art Deco Hollywood**

Named genre: *Art Deco Cinema* — the aesthetic of 1920s/30s Hollywood: rich and warm, theatrical and glamorous, with a dark velvet theatre backdrop against warm projection light.

### Palette
- Background: `#0D0906` (near-black with warm undertone — like a dark cinema)
- Surface cards: `#F4E4B4` (aged parchment / old filmstrip)
- Cinema gold: `#C49A2A` (Art Deco gilt lettering)
- Velvet red: `#9B1919` (classic cinema seats / marquee)
- Projection cream: `#FFF8E7` (light from the projector)
- Type on dark: warm ivory, type on parchment: espresso brown

### Typography
- **Playfair Display** (900 weight) — display headlines, step numbers, movie-poster scale
- **IM Fell English** italic — scene description input and viewfinder text (old manuscript feel)
- **Courier Prime** — all UI labels, metadata, prompt output (typewriter/screenplay aesthetic)
- **Inter** — body copy, descriptions

### Signature Elements
1. **Animated film strip perforations** — The left and right edges of the screen are 52px-wide film strips with scrolling perforation holes (CSS keyframe animation, left scrolls down, right scrolls up — mimicking film advancing through a projector)
2. **Director's viewfinder** — A 16:9 widescreen frame with corner-mark brackets, rule-of-thirds grid overlay, center crosshair, and four corner labels showing your current Shot Type / Movement / Lighting / Mood in real-time
3. **35mm film strip preview** — Five "frames" flanked by sprocket holes above and below, each displaying an emoji icon + label for your current Shot / Move / Light / Mood / Grade selection
4. **Typewriter prompt generation** — Prompts are typed character-by-character (speed scales with text length) to evoke a screenplay being written on paper
5. **Clapperboard clap animation** — The "CALL ACTION" generate button causes the clapperboard emoji to physically rotate/clap when clicked
6. **"SLATE IT" copy button** — Film production terminology throughout the UI

### Anti-Sameness
Compared to previous builds:
- *VibeSpec* used Swiss Brutalism — white background, acid green, black borders
- *ContextCraft* used Engineering Blueprint — navy, blueprint blue, technical schematic
- *Back to 2016* used Tumblr Scrapbook — hot pink, cream, polaroid cards
- **CinePrompt** is dark + warm + gold + parchment — no overlap with any prior palette or aesthetic

## Technical Notes

- Pure frontend: single `index.html`, no JS framework, no build step
- Prompt generation is real-time (400ms debounce on scene input changes)
- Clipboard API with graceful fallback
- All decorative elements use `aria-hidden="true"`, live regions on prompt output
- `nginx:alpine` Docker image, ~5MB total
- Port: 3114 on airstream (100.97.65.28)
