## Why Dry Run Was Chosen

GateMate-level specificity: millions of homebrewers, recurring weekly/monthly use, incumbent tools (BeerSmith) are paid desktop-only with outdated UX. A clean, single-page, no-account-needed calculator that gives instant live feedback on OG/FG/ABV/IBU/SRM would get bookmarked and shared. The visual SRM beer glass changing color in real time as you add grains is a satisfying, memorable feature.

## What Was Built

**Core features:**
- **Grain Bill** — 35+ malts, adjuncts, and sugars with PPG and Lovibond values. Calculates OG using standard gravity points formula.
- **Hop Schedule** — Tinseth IBU formula (bigness factor × boil time factor). Hop variety autocomplete. Supports dry hops (time=0, excluded from IBU).
- **Yeast** — 10 common strains with standard attenuation values + custom attenuation. Calculates FG and ABV.
- **Live Stats** — OG, FG, ABV, IBU, SRM, calories (per 12 oz) — all recalculate on every keystroke
- **SRM Beer Glass** — SVG pint glass fills with the actual calculated beer color using the Morey SRM formula and a 40-step SRM color array. Foam and bubbles appear when beer is in range.
- **Style Guide Comparison** — 15 BJCP-inspired styles with OG/ABV/IBU/SRM range bars and in/out-of-range indicators
- **Brew Day Checklist** — Auto-generated multi-phase checklist (Day Before → Strike/Mash → Sparge/Boil → Fermentation → Packaging) that incorporates recipe-specific details (grain weight, boil volume, hop additions by time, fermentation temp, dry hop instructions)
- **Print Support** — Clean print layout for recipe card

**Formulas used:**
- OG: `1 + Σ(grain_ppg × lbs × efficiency) / batch_gallons / 1000`
- FG: `1 + (OG-1) × (1 - attenuation)`
- ABV: `(OG - FG) × 131.25`
- IBU (Tinseth): `Σ(oz × AA% × utilization × 7489) / batch_gallons`
  - BF = `1.65 × 0.000125^(ogPoints/1000)` (ogPoints = (OG-1)×1000)
  - TF = `(1 - e^(-0.04×time)) / 4.15`
- SRM (Morey): `1.4922 × (MCU^0.6859)` where MCU = Σ(lbs × °L) / gallons
- Calories: `(ABW × 2.5 + (FG-1.008) × 819) × 12`

**Bugs caught and fixed:**
1. Tinseth bigness factor exponent was `ogPoints/1000 - 1` (wrong) → fixed to `ogPoints/1000`
2. SRM label lookup used raw decimal SRM — `4.46` fell between range brackets → fixed to use `Math.round(SRM)`
3. `addHop({time:0})` used `defaults.time||60` — JavaScript's `0||60` returns `60` → fixed to explicit undefined check
