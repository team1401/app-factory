## Why PatchSheet Was Picked

PatchSheet wins because it solves a **specific, recurring pain point** with no good existing tool:

- Every live sound engineer re-creates input lists from scratch for every show — in Excel, Google Sheets, or even handwritten on gaffer tape
- The pain is real and universal: touring engineers, local venue techs, and event production companies all hit this weekly
- The output (a printed patch sheet) is a physical artifact with clear utility — you hand it to the backline crew, the monitor engineer, the stage manager
- Existing spreadsheet templates are fragile, not optimized for printing, and have no phantom power tracking or monitor mix toggles built in
- The "4-piece rock" template alone saves 20 minutes of setup per show for a house engineer

The "Console Scribble Strip" design direction was a natural fit — monospace labeling, dark strip headers with LED meter accents, neon group color chips per instrument category. It looks like something that belongs in a rack or on a console surface.

## Build Summary

- React + TypeScript + Vite for a fast, no-backend SPA
- localStorage persistence — no server needed, data survives refresh
- 3 built-in templates: 4-Piece Rock (15 ch), Podcast 2-Mic, Acoustic Duo
- Channel table: Ch#, Source, Mic/DI, Stand, Phantom 48V toggle, Stage Position, Group, M1–M6 monitor toggles, Notes
- Group color chip system: Drums (orange), Bass (teal), Guitar (yellow), Keys (green), Vox (pink), BGV (purple), etc.
- Print View: optimized A4/Letter layout with group color legend, phantom summary, monitor dot matrix
- Import/Export JSON per show
- Reorder via up/down buttons, duplicate row, remove row
- Scribble strip table header with LED meter accent bar (CSS gradient)
- Deployed to Airstream port 3180 via Docker
- servershed.net updated — PatchSheet added to apps.json (now #1 entry)
