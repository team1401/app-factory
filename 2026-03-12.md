## Brainstorm: 7 Problem-First Ideas

### 1. Ham Radio QSO Logger ✅ SELECTED
- **Pain:** 700K+ licensed US amateur radio operators have zero modern web-based logging tools. Existing software (Ham Radio Deluxe, Log4OM, CQRLOG) is outdated, Windows-only, and bloated with complexity. Every radio operating session requires logging contacts.
- **Who:** Licensed amateur radio operators globally (700K+ in US alone)
- **Frequency:** Every radio session — serious operators log several times per week
- **Existing solutions:** Ancient desktop apps with terrible UX, nothing modern or web-based
- **Revenue path:** Free for basic logging; paid tier for DX cluster integration, LOTW sync, award tracking (DXCC, WAS), multi-device sync

### 2. Equilibrium Cure Calculator for Home Charcuterie
- **Pain:** Home curers making salumi, bacon, guanciale must calculate salt and nitrate ratios by meat weight. Getting it wrong = inedible (too salty) or dangerous (botulism). The math is real and consequential.
- **Who:** Growing home charcuterie community (~100K active US practitioners)
- **Rejected because:** Too adjacent to BakerMath (kitchen/cooking domain, built 2 days ago)

### 3. Freelance Scope Creep Tracker
- **Pain:** Freelancers lose thousands annually to undocumented scope additions. No tool specifically tracks scope changes and generates change orders.
- **Who:** Freelance developers, designers, writers, consultants
- **Rejected because:** Billing/money theme is adjacent to MeetCost (built yesterday)

### 4. Kiln Firing Schedule Logger for Ceramicists
- **Pain:** Studio potters log firing schedules (temperature ramps, holds, cooling curves) in paper notebooks. No digital tool for reproducing successful firings.
- **Who:** Studio potters and ceramic artists
- **Good but:** Requires rich data persistence; less immediately useful than a calculator-style tool

### 5. Sprint Retrospective Facilitator
- **Pain:** Scrum Masters run retros every 2 weeks. Miro/Retrium cost $$$.
- **Who:** Engineering teams, Agile coaches
- **Rejected because:** Requires multi-user real-time to be truly useful; single-user value is limited

### 6. Pressure Canning Validator
- **Pain:** Home canners need USDA-validated processing times to prevent botulism. Existing resources are confusing and spread across ugly government websites.
- **Who:** Homesteaders, home food preservers
- **Good but:** Mostly a lookup table; limited interaction model

### 7. Tattoo Aftercare Tracker
- **Pain:** Multi-week aftercare protocol with specific timelines. People forget steps, ruin expensive tattoos.
- **Who:** Anyone getting a tattoo (millions/year)
- **Rejected because:** Finite use case (heals and you stop using it); limited return usage

## Why Ham Radio Won

The ham radio logger wins on all criteria:
1. **Massive underserved community** — 700K+ US hams, millions globally, all need logging
2. **Daily/weekly use** — every radio session requires logging contacts
3. **Worst existing tooling of any candidate** — the best existing apps are genuinely ancient
4. **ADIF export adds real value** — the output is actually usable with LOTW, eQSL, Club Log
5. **Completely outside Brian's world** — he'll see something from a totally different universe
6. **Product Hunt gold** — ham operators are active in tech communities and would share this widely
7. **Clear freemium path** — basic logging free, advanced features (DX cluster, award tracking) paid

The GateMate comparison holds: this solves a specific, recurring frustration (logging QSOs with a modern tool) that has no good existing solution.

## Design Direction

**Style:** "Cold War SIGINT Terminal"

Inspired by Cold War-era signals intelligence monitoring stations, ham radio shacks of the 1960s–80s, and vintage oscilloscope/spectrum analyzer equipment. The dual-color scheme (phosphor green for data, amber for frequency readouts) mimics real CRT equipment used in both military SIGINT operations and civilian ham shacks.

- **Palette:** Near-black (#030802) bg, Phosphor green (#39FF14) primary, Amber (#FF9900) accents, Olive (#4A5A30) labels
- **Typography:** Share Tech Mono (body), Orbitron (callsigns/big numbers), IBM Plex Mono (labels)
- **Signature Element:** CSS CRT scanlines (repeating-linear-gradient overlay), phosphor glow text-shadow, amber frequency readout panel styled as analog instrument display
- **Anti-sameness check:** First and only terminal/phosphor-green build in the log. Completely distinct from all 25+ prior styles.
