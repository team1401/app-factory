## Winning Idea: #1 — HaulCalc

**Why this one:**

The pain is intense AND daily (multiple load evaluations per shift). The math is genuinely complex: `gross revenue − loaded fuel cost − deadhead fuel cost − fixed costs per day = true net`. Owner-operators currently do this in their heads, on phone calculators, or in random spreadsheets. No focused, purpose-built web tool exists for this specific workflow.

The target market (~350,000 owner-operators in the US) is almost entirely outside Brian's world — he'd never have thought of it. The tool has a clear freemium path (save profiles, load history, rate-per-mile benchmarks by lane) and a very specific, describable user ("truckers evaluating loads on DAT or Truckstop.com").

GateMate comparison: Both solve a "which one should I pick" decision for people who make that decision repeatedly. GateMate: which layover airport. HaulCalc: which load.

**Style name:** "Diesel Dashboard"  
**Inspiration:** American long-haul truck cab instrument clusters — the analogy of "tachometer shows engine health" → "gauge shows load profitability" is natural and memorable.

**Palette:**
- Background: `#0F1114` (near-black gunmetal)

- Surface 2: `#1E2228`

- Red (PASS zone): `#E84040`
- Yellow (CONSIDER zone): `#F5C842`
- Green (HAUL IT zone): `#36D17A`

**Typography:**
- Orbitron (700/900) — digital instrument readout for all numbers

**Signature element:** 180° semicircle SVG tachometer with three color-coded arc zones. Needle animates with spring-easing on every keystroke. The "dead reckoning" feel — you type your load details and the needle swings in real time.

**Anti-sameness check:** First instrument-cluster / automotive aesthetic in the log. No dark glassmorphism. Amber glow is completely different from any prior palette.

## Architecture

**Type:** Pure frontend (HTML/CSS/JS), no backend  
**State:** localStorage for truck profile  
**Deployment:** nginx:alpine Docker image

**Key components:**
1. **Truck Profile** (collapsible card) — MPG, diesel $/gal, avg speed, fixed $/day — saves to localStorage
2. **Load Details** (card) — Rate per mile or flat, loaded miles, deadhead miles, optional label
3. **Gauge** (SVG, 420px wide) — 180° arc with RED/YELLOW/GREEN zones; needle rotated by CSS transform with spring easing
4. **Stats grid** (6 cards) — Gross, Fuel, Fixed, Net, Drive Hours, Eff. $/hr
5. **Break-even bar** — visual margin indicator
6. **Verdict banner** — PASS / RISKY / CONSIDER / HAUL IT with icon + sub-text
7. **Load Comparison** (bottom full-width) — up to 3 loads, best values highlighted green

**Calculation logic:**
```
gross      = ratePerMile × loadedMiles  (or flatRate)
fuelCost   = (loadedMiles + deadMiles) / mpg × dieselPrice
driveHours = (loadedMiles + deadMiles) / avgSpeed
driveDays  = driveHours / 11  (HOS: 11-hr driving day)
fixedCost  = driveDays × fixedPerDay
net        = gross - fuelCost - fixedCost
netPerMile = net / loadedMiles
hourlyRate = net / driveHours
```
