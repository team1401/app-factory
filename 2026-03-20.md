## Concept

**Problem:** Full-timers visit dozens of campsites a year but have no lightweight way to remember what made each one good or bad. "Was that BLM site near Moab level? What was the cell signal like at Lone Rock?" — these questions come up constantly when planning repeat visits.

**Solution:** SiteScore is a campsite memory app. Log sites with structured ratings across 7 criteria, add hookup tags, notes, map links, price, and nights stayed. Search and filter later to find your best-rated quiet boondock or the nearest full-hookup park with WiFi.

**GateMate test:** Any full-timer who's ever Googled their own previous campsite would say YES immediately.

## Build

**Visual Style:** Rugged field-notes aesthetic. Deep brown/bark background, cream/parchment cards, forest green card headers, rust red accents, gold score badges. Space Mono for labels/data, Libre Baskerville for body. Not generic — feels like a leather-bound camp journal.

**Features Built:**
- 7-criterion rating system with live sliders: Signal, Level, Shade, Quiet, Views, Facilities, Value
- Auto-calculated overall score (1 decimal)
- Color-coded bar charts on each card (rust → gold → pine progression)
- 9 hookup/amenity checkboxes with tag badges on cards
- Site type selector (campground, boondock, RV park, state park, national, Thousand Trails, Harvest Hosts)
- Notes, price/night, map link, date visited, nights stayed
- Favorite toggle with ⭐ filter
- Full-text search across name/location/notes
- Sort: recent, score high/low, A-Z, favorites first
- Tag filters: Electric, Water, WiFi, Boondock, Pet-Friendly, Favorites
- localStorage persistence
- 3 seed sites pre-loaded (Lone Rock, Catalina SP, Terlingua Ranch)
- Mobile responsive

**Single HTML file:** ~38KB, zero external dependencies (fonts inline via Google import — no local files needed).

## Deploy

```bash
# Create app dir and upload
mkdir -p /home/helix/apps/sitescore
scp index.html helix@192.168.50.5:/home/helix/apps/sitescore/

# nginx.conf for host networking on port 3235
# (written to /home/helix/apps/sitescore/nginx.conf)

# Docker run
docker run -d --name sitescore --network host \
  -v /home/helix/apps/sitescore:/usr/share/nginx/html:ro \
  -v /home/helix/apps/sitescore/nginx.conf:/etc/nginx/conf.d/default.conf:ro \
  nginx:alpine
```

**Note:** `--network host` with port 80 conflicts with existing containers. Used custom nginx.conf to bind to port 3235 directly. Needed `chmod 644` on HTML file and `chmod 755` on directory for nginx to serve.
