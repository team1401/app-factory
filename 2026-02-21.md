## Visual Identity

**Style Genre:** Memphis Design Revival  
**Inspiration:** Ettore Sottsass / Memphis Group (1980s Italian design movement)

**Palette:**
- Background: `#F5EDD8` (warm cream)
- Primary: `#FF3355` (coral red — Subject header)
- Secondary: `#0066FF` (electric blue — Action header)
- Accent: `#FFD500` (vivid yellow — Camera header, buttons)
- Mint: `#00C97A` (Environment header, tips card)
- Orange: `#FF7A00` (Lighting header)
- Purple: `#7B2FF7` (Visual Style header)
- Black: `#1A1A1A` (borders, shadows — 3px solid everywhere)

**Typography:** Space Grotesk (bold geometric sans) + DM Mono (assembled prompt output)

**Signature Element:** **Prompt DNA Strand** — a horizontal bar of 7 color-coded pill blocks that transition from 20% opacity (empty) to full opacity (filled) as each prompt component is selected. A quality score grades from "NO SEQUENCE" → "BEGINNER" → "DEVELOPING" → "INTERMEDIATE" → "CINEMATIC" → "★ MASTERSHOT" based on how many components are filled. The entire design uses zero gradients, thick black borders, flat opaque colors, and offset box shadows.

**Anti-sameness check:** PASSED — opposite of glassmorphism in every dimension: cream (not dark), flat (not frosted), loud (not subtle), thick borders (not thin translucent ones).

**Image QA score:** 8.5/10 (vision model assessment)

## Architecture

- **Type:** Pure frontend SPA — single HTML file (56KB)
- **Backend:** None — fully self-contained
- **Storage:** localStorage (saved prompts, max 20)
- **Deployment:** Docker (nginx:alpine serving static file)

**Prompt components (8 total):**
1. Subject — who/what (custom text + 8 chips)
2. Action — what's happening (custom text + 8 chips)
3. Environment — where (custom text + 8 chips)
4. Camera — movement & angle (8 chips)
5. Lighting — time & atmosphere (8 chips)
6. Visual Style — aesthetic treatment (8 chips)
7. Mood — emotional quality (8 chips)
8. Motion — pacing & energy (7 chips)

**Features:**
- Real-time assembled prompt
- DNA Strand visualization
- Quality scoring (0-8 scale)
- 4 viral presets (Cinematic Epic, Anime Fantasy, Neo-Noir, Nature Doc)
- 3 example prompts (Deep Ocean Ballet, Neo-Tokyo Pursuit, Mars Revelation)
- Copy to clipboard, export as .txt
- Save up to 20 prompts in localStorage
- Random shuffle
- Responsive (mobile + desktop)
