# App Factory — 2026-03-28

## Brainstorm

### 1. Reef Tank Chemistry Tracker
**Pain point:** Reef hobbyists must test 8–11 water parameters weekly (alkalinity, calcium, magnesium, pH, salinity, nitrate, phosphate, ammonia, nitrite, iodine, temperature). If alkalinity drifts even 1–2 dKH outside range, coral bleaches and dies — potentially $5,000+ of livestock. Most reefers track this on paper, whiteboards, or spreadsheets. No good dedicated web tool exists. ForeFlight for reef doesn't exist.
**Who:** ~1M US reef aquarium hobbyists, high-spend audience (tanks cost $2K–$50K+)
**Verdict: SELECTED** — strongest problem/solution fit, obsessed niche audience, clear freemium path

### 2. Mobile Notary Session Journal
**Pain point:** Notaries in most states are legally required to keep a detailed journal of every notarization — date, signer name, doc type, ID type/number. ~800K notaries in the US do this on paper. If audited or sued, paper journals are irreplaceable. Very few digital tools exist.
**Who:** Mobile notaries (especially Notary Signing Agents doing loan signings)
**Verdict:** Strong, but requires more complex data entry / legal disclaimer concerns

### 3. Print-on-Demand Margin Calculator
**Pain point:** POD sellers on Etsy/Printful calculate margin constantly for every product: base cost + Etsy fee (6.5%) + payment processing + shipping = what do I actually make? Calculator apps don't understand POD fee structures.
**Who:** ~500K+ POD sellers on Etsy/Amazon Merch
**Verdict:** Good but simpler — less retention than chemistry tracking (done it, move on)

### 4. Pilot Flight Logbook & Currency Tracker
**Pain point:** Private pilots must track flight hours AND maintain currency (3 takeoffs/landings per 90 days, IFR currency). ForeFlight is $100+/year. Simple logbook apps don't do currency tracking.
**Who:** ~600K private pilots, can't legally fly if currency lapses
**Verdict:** Strong candidate — but ForeFlight and existing paid apps occupy this space better

### 5. Small Fab Shop Job Tracker
**Pain point:** Small metal fabrication/welding shops run on whiteboards. Track: customer, material specs, hours estimated vs. actual, billing status. Nobody has built a clean digital version for the $50K/year solo shop owner.
**Who:** ~400K small welding/fab shops
**Verdict:** Good niche but needs backend/auth for real utility — Tier 2 candidate

### 6. Specialty Coffee Brew Log
**Pain point:** Serious home baristas experiment daily with grind, dose, ratio, temperature, extraction time. Want to recreate great cups — currently use notecards. Growing market.
**Who:** Specialty coffee enthusiasts
**Verdict:** Close to journal/logger pattern — overrepresented in app stores

### 7. Pre-Signing Real Estate Disclosure Tracker
**Pain point:** Real estate agents need to track which of 15–30 disclosure documents have been sent, signed, and returned per transaction.
**Who:** ~1.5M active real estate agents
**Verdict:** Better as a Tier 2 — needs multi-party coordination and auth

---

## Winner: Reef Tank Chemistry Tracker → **ReefLog**

**Why this one:**
- Real, specific, recurring pain (weekly) — not a one-time task
- Expensive consequences of failure (coral death) create strong retention motivation
- ~1M passionate, high-spending hobbyists who WILL talk about tools that work
- Nothing good exists in the web app space (ReefBot = hardware, Reef2Reef = forum threads)
- Completely outside Brian's world — he'll find it interesting/surprising
- Clear freemium: free = 1 tank / Pro = cloud sync + alerts + export
- Natural Product Hunt audience

### Design System
- **Style:** De Stijl Data — Mondrian geometric grid aesthetic applied to chemistry data
- **Palette:** Mondrian Blue (#1A3ACC), Mondrian Red (#CC1A1A), Mondrian Yellow (#E8C620), White (#FAFAF8), Black (#0D0D0D), Status Green (#1A7A3A)
- **Typography:** Bebas Neue (display/labels) + Space Grotesk (UI) + Space Mono (data values)
- **Layout:** Three-column grid — tank list (left), parameter tiles (center), trend + history (right)
- **Signature element:** Parameter cells as geometric Mondrian tiles separated by thick 3–5px black borders; status indicated by bottom border color (green/yellow/red/dark red); entire layout reads as a living Mondrian composition with data

### Features Built
- Multi-tank support with color-coded health badges (OK/WARN/CRIT)
- Real-time input validation — out-of-range feedback as you type
- Parameter trend sparklines with target range bands
- Test history feed (last 30 entries)
- Water change logging with % volume
- Trend arrows (↑↓→) on each parameter tile
- Alert banners (CRITICAL + WARNING) with dismiss
- Demo data auto-seeded on first load
- Offline-first (localStorage)
- Accessible (ARIA labels, keyboard nav, WCAG AA contrast)

### Revenue Potential
Free tier: 1 tank, 90-day history, local storage
Pro ($4.99/mo): unlimited tanks, cloud sync, export CSV/PDF, dosing reminders, email alerts
Estimated SAM: 100K addressable reefers × $60/yr = $6M ARR potential at scale
