TOTAL SOURCE CODE: ~24.5KB (highly optimized!)

Key Technologies:
─────────────────
• React 18.3.1         → UI framework
• Vite 5.2.0           → Build tool (HMR)
• Tailwind CSS 3.4.1   → Utility-first CSS
• Framer Motion 11.0.8 → Animation library
• Socket.io-client 4.7 → WebSocket client
• Lucide React 0.344   → Icon library
• Nginx (Alpine)       → Production server

Design System:
──────────────
• Colors: Blue (#3B82F6) vs Orange (#F97316)
• Dark theme: #030712 → #374151
• Typography: Inter font family
• Glassmorphism: bg-white/5 + backdrop-blur-xl
• Animations: Framer Motion + CSS keyframes

Production Features:
────────────────────
✅ Multi-stage Docker build
✅ Nginx with gzip, caching, security headers
✅ Health checks (/health endpoint)
✅ SPA routing fallback
✅ Environment variable support
✅ Mobile responsive
✅ WebSocket auto-reconnect
✅ Loading & error states

Quick Start:
────────────
Development:  ./setup.sh dev
Build:        ./setup.sh build
Docker:       ./setup.sh docker

Or manually:
  npm install
  npm run dev     → http://localhost:5173
  npm run build   → ./dist/
  
Docker:
  docker build -t debate-arena-frontend .
  docker run -p 8080:80 debate-arena-frontend

Requirements:
─────────────
• Node.js 18+
• npm 9+
• Docker (for containerization)

Environment:
────────────
VITE_API_URL = Backend WebSocket URL (default: http://localhost:3000)
