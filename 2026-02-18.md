# App Factory — 2026-02-18

## What Was Built

**ContextCraft** — AI Context Window Planner

A visual planning tool for understanding and managing AI model context windows. Users add "content blocks" (system prompts, code files, documents, chat history, images, custom text) and watch a blueprint architectural diagram fill up in real time, showing exactly how much of their chosen model's context window they're consuming.

## Why This

The **context window arms race** is one of the defining AI stories of early 2026 — GPT-4o (128K), Claude (200K), Gemini 2.0 Flash (1M), and even 2M-token windows are now real. Yet most developers have no mental model for what those numbers actually mean day-to-day. Questions like "Can I fit my whole codebase?" or "How much chat history can I keep?" are universal but unanswered visually. This tool makes it concrete, visual, and instantly useful.

## Features

- **12 AI models** across OpenAI, Anthropic, Google, DeepSeek, Meta, Mistral — all with real context window sizes and pricing
- **6 content types** with preset sizes: System Prompt, Code File, Document, Chat History, Image/Vision, Custom
- **5 preset scenarios**: RAG Pipeline, Code Review, Long-Doc Q&A, Full Codebase, Multimodal
- **Blueprint building visualization**: fills from bottom as blocks are added; blocks are color-coded by type; 80% warning line; overflow zone with diagonal red stripes
- **Cost estimation** based on published input token pricing
- **Real-world comparisons**: novels, Wikipedia articles, newspaper pages, emails, tweets
- **Click-to-highlight**: clicking a block in the list highlights it in the building diagram (and vice versa)
- **Auto-save** to localStorage — state persists across page loads
- **100% client-side** — no backend, no API keys

## Style Direction

**Precision Engineering Blueprint**

- **Genre**: Architectural/technical schematic — like a building cross-section drawn in Blueprint CAD
- **Background**: Deep navy (#060F1A) with CSS multi-scale grid lines (80px major, 16px minor) in blueprint blue
- **Palette**: Blueprint blue (#4A9EFF), cream annotation labels, yellow warning (#FFD60A), red danger (#FF3B30), green safe (#34C759), dark panel surfaces
- **Typography**: JetBrains Mono (monospace) used for ALL UI text — not just code. IBM Plex Sans Condensed for the app logo. This "everything is a technical readout" choice makes the design feel like a real instrument.
- **Layout**: Two-column — sticky building visualization on the left, management panel scrolls on the right. Comparison cards span full width at the bottom.
- **Signature element**: The animated building cross-section:
  - Hatched diagonal pattern in the empty (unused) space — blueprint convention for "to be filled"
  - Corner marks (L-shaped lines) on the building outline — classic blueprint annotation
  - Dimension arrows on the right side with model name + context size
  - Scale ruler tick marks on the left: 0%, 25%, 50%, 75%, 100%
  - Yellow dashed line at 80% threshold
  - Blocks fill from the bottom with smooth flex transitions
  - Red diagonal stripes in overflow zone
